# Agendar Tarefas 2.0

Aplicação web desenvolvida com HTML, CSS, Materialize CSS, JavaScript e jQuery para cadastrar e gerenciar tarefas.

## Funcionalidades

- Cadastro de tarefas com título e observações.
- Validação dos campos obrigatórios.
- Seleção de prioridade: Baixa, Média e Alta.
- Conclusão e reabertura de tarefas.
- Exclusão de tarefas com confirmação.
- Filtro por tarefas pendentes e concluídas.
- Contadores de tarefas cadastradas, pendentes e concluídas.
- Limpeza automática dos campos após o cadastro.
- Foco automático no campo Título.
- Armazenamento local utilizando localStorage.
- Interface responsiva para computadores e dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- Materialize CSS
- JavaScript
- jQuery
- Manipulação do DOM
- localStorage

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um banco de dados.

É necessária conexão com a internet para carregar as bibliotecas externas do Materialize, jQuery e Material Icons.

## Objetivo acadêmico

Projeto desenvolvido para praticar formulários, validação de campos, eventos, manipulação do DOM com jQuery, armazenamento local e estilização de interfaces web.
